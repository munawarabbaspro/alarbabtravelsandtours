# AL ARBAB TRAVEL AND TOURS — website

Static site generator and the built site.

## Layout
- `src/` — source: `build.py` (generator), `data/` (site data, images, WhatsApp routing), `assets/` (CSS, JS, photos, logos).
- `dist/` — built site (generated by the build; deploy this folder).
- `tools/` — QA and audit scripts (`check.js`, `qa.js`, `links.js`, `predeploy.py`).

## Build
    python src/build.py

Writes the site to `dist/`.

## Check before deploy
    python tools/predeploy.py
